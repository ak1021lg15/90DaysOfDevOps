Docker CI/CD using Github Actions

A simple demonstration of building, tagging, pushing, pulling and running a Docker image using GitHub Actions.

🚀 Deployment successful — Docker image is running locally!
🔨

Docker Build

GitHub Actions automatically builds the Docker image from the Dockerfile.

🏷️

Image Tags

The image uses both latest and a short Git commit SHA tag.

🐳

Docker Hub

The image is pushed to Docker Hub and can be pulled from another machine.

🌿

Branch Control

Feature branches build the image, while Docker Hub pushes happen only from the main branch.
